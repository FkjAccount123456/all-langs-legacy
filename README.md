# 弯路
观察前面的脉络可以看出，module i1直至i32，以及Butterfly自身的发展都是小步快跑的渐进策略  
其根本可能性在于2022几乎全年都处在居家学习中，且知识都比较浅，不涉及哪怕稍微深入一点的编译原理  
在穷尽全部这类教程之后，由于数理知识的不足我也难以继续学习，显然我自制编程语言的发展要不可避免地走上弯路了  
同时居家学习时期也接近尾声  
因此，2022年后期实现Butterfly之后的语言实现都偏向于巩固和实用而非创新，几乎再也没有任何实质性的发展，而集中于编程能力的提升  
不是说这不好，而是说我本有机会使走上那条理论学习和不断突破性创新路线的我到现在真正成为计算机科学人才的  
这种实现在2023年开学后也因为时间原因和编辑器开发而逐渐减少，直至现在这种一年一个纪念作的形式  
不过也因此，且后来重心放在了编辑器上，其实弯路没走多少，加起来不过相当于2022全功率的两个月？却绵延了4年之久
可惜了……
